# 위베이프 마케팅 AI 조직 설계서 v0.2

**작성**: 2026-08-17 · **관리자**: 장현진 팀장(마케팅·영업총괄) · **상태**: v0.2 — 관리자 결정 5건 반영, 뼈대 우선 일정
**전제**: 블로그는 이 조직의 첫 번째 "라인"일 뿐이다. 이 문서는 마케팅 전체를 AI 직원 조직으로 짜는 틀이다.

---

## 1. 구조 한 장 요약

조직은 **가로(기능팀 5개) × 세로(채널 라인)** 격자다. 모든 콘텐츠는 어떤 채널이든 같은 5단계를 지난다.

```
              트렌드조사 → 이슈조사 → 작성 → 검수 → 업로드
블로그 라인      ○          ○        ○      ○      ○
SNS 라인         ○          ○        ○      ○      ○
사진 라인        ○          ○        ○      ○      ○
영상 라인        ○          ○        ○      ○      ○
POP 라인         ○          ○        ○      ○      ○
```

- **기능팀(가로)**은 "일하는 방식"이다. 트렌드조사팀은 채널이 뭐든 같은 방식으로 트렌드를 본다.
- **채널 라인(세로)**은 "결과물 형태"다. 블로그 글, SNS 카드, 사진, 영상, 매장 POP.
- 기능팀 하나는 여러 라인을 동시에 섬긴다. 트렌드조사팀이 낸 "이번 주 트렌드 보고" 하나를 블로그·SNS·영상 작성팀이 다 받아 쓴다. → **팀 수는 5개로 고정, 라인은 늘어나도 팀은 안 늘어난다.**
- 각 팀 안에 있는 개별 AI 직원은 "역할 정의서 한 장"으로 존재한다.

## 2. 기능팀 5개 정의

### 2-1. 트렌드조사팀 — "지금 사람들이 뭘 보고 있나"
- 하는 일: 쇼츠·릴스·스레드·커뮤니티·검색어에서 우리 고객층(성인 흡연자, 인천·부천 생활권, 중국인 방문객)이 반응하는 소재·말투·형식을 매주 수집.
- 직원 예시: 쇼츠 트렌드 리서처 / 지역 상권 리서처(부천·인천 동네 이슈, 맛집, 행사) / 중국인 고객 관점 리서처(소홍서·웨이보에서 한국 매장 소비 트렌드) / 서브컬처·비주얼 트렌드 리서처(카드뉴스·POP 디자인 흐름)
- 출력: 「주간 트렌드 보고」 1건. 소재 10개 + 각 소재를 어느 라인에서 쓰면 좋을지 표시.
- 규칙: 제품·맛·니코틴 트렌드는 수집하지 않는다(써먹을 수 없으니 헛수고). 매장·지역·생활·형식 트렌드만.

### 2-2. 이슈조사팀 — "지금 뭘 조심해야 하나"
- 하는 일: 규제·단속·법 개정·플랫폼 정책 변경·경쟁사 동향·우리 매장 관련 온라인 언급 감시.
- 기존 자산: **장대운 주임 「위베이프 이슈 모니터」**가 이 팀의 데이터 소스. 새로 만들지 않고 읽는다.
- 직원 예시: 규제 감시자(담배사업법·국건법·플랫폼 정책 D-day) / 평판 감시자(네이버 리뷰·카페·블로그에서 매장 언급) / 경쟁 감시자(주변 매장 개업·폐업·마케팅)
- 출력: 「주간 이슈 브리핑」 1건 + 긴급 시 즉시 알림. **금지·주의 표현 기준서의 갱신 담당**이 이 팀이다.

### 2-3. 작성팀 — "만든다"
- 하는 일: 트렌드 보고 + 이슈 브리핑 + 편집장 기획안을 받아 채널별 결과물을 만든다.
- 직원 예시(라인별): 블로그 작가(리뷰형·후기형) / SNS 작가(스레드·인스타·페북·X 채널별 톤) / 사진 디렉터(촬영 지시서·보정 가이드, 나중엔 이미지 생성) / 영상 작가(숏폼 대본·컷 리스트·자막) / POP 디자이너(매장 안내물·가격표 외 규제 준수 안내물 문안·레이아웃)
- 기존 자산: 김형진 팀장 블로그 자동화, 장대운 주임 SNS 자동화(Gemini)는 **작성팀 소속 도구**로 편입. 새 작가 AI와 병렬 운영 후 합침.
- 출력: 각 라인 결과물 + "어떤 기획안·트렌드 소재를 썼는지" 꼬리표.

### 2-4. 검수팀 — "내보내도 되나"
- 하는 일: 모든 라인 결과물을 규제·브랜드·품질 3중으로 거른다.
- 직원 예시: 규제 검수관(기준서 10항목, 채널 무관) / 브랜드 검수관(직영·재고 안정·신뢰 멘트·지점 정보 정확성) / 품질 검수관(AI 티 나는 문체, 사진 구도, 영상 길이·자막)
- 출력: 통과 / 수정 / 반려 + 한 줄 사유. **사람(관리자)이 최종 승인하는 유일한 지점.**
- 규칙: 규제 검수는 자동 반려 권한이 있다. 나머지는 의견만.

### 2-5. 업로드팀 — "내보내고 기록한다"
- 하는 일: 승인된 결과물을 채널에 예약·발행하고, 발행 기록과 반응(조회·댓글·리뷰)을 다시 트렌드조사팀·검수팀에 돌려준다.
- 기존 자산: 장대운 SNS 자동 발행(스레드·인스타), 네이버 리뷰 답글 자동화, 고아현 인스타 리포트 제안 → 전부 이 팀.
- 출력: 「주간 발행 결과」(무엇을 언제 어디에, 반응은 어땠나).

### 2-6. 관점 패널 — "다르게 보는 사람들" (팀이 아니라 자문단)

기능팀 5개가 "일하는 순서"라면, 관점 패널은 **"어떤 눈으로 보느냐"**다. 취향과 전문성이 뚜렷한 인물들을 두고, 기획·작성 단계에서 같은 과제를 각자의 눈으로 보게 한 뒤 편집장이 취합한다. 팀에 소속되지 않고, 편집장이 필요할 때 부른다.

인물마다 정의서에 들어가는 것: 좋아하는 것과 그 이유 / 참고하는 작품·사례 10개 / 말투와 문장 습관 / 이 사람이 마케팅을 볼 때 항상 던지는 질문 3개 / **이 사람의 관점이 결과물로 바뀌는 규칙**(이게 없으면 장식이 된다).

| 인물 | 특성 | 마케팅에서 맡는 눈 | 잘 붙는 라인 |
|---|---|---|---|
| 소설 읽는 사람 | 서사·인물·복선 | 후기형 글의 이야기 구조, "이 매장에 어떤 사람이 왜 오는가"를 인물로 만든다 | 블로그 후기형, 영상 스토리 |
| 영화 보는 사람 | 장면·컷·리듬·조명 | 사진 구도, 숏폼 컷 리스트, 매장 공간을 "장면"으로 본다 | 사진, 영상, 매장 연출 |
| 시 읽는 사람 | 압축·여백·한 줄 | SNS 한 줄, POP 문안, 해시태그 대신 남는 문장 | SNS, POP |
| 만화·서브컬처 사람 | 캐릭터·컬러·세계관 | 비주얼 아이덴티티, 캐릭터 활용, 젊은 성인층 감각(청소년 연상 금지선은 검수팀이 잡음) | 사진, POP, 버블몬 연계 |
| 광고 카피라이터 | 한 문장의 힘, 클레임 | 직영·재고 안정 메시지를 매번 다르게 말하는 법 | 전 라인 |
| 행동경제·소비심리 | 동선, 선택, 신뢰 신호 | 고객이 매장을 고르는 실제 이유, 방문 유도 문장의 심리 | 블로그, POP |
| 동네 토박이 | 인천·부천 생활권 | 지역 SEO 키워드, 상권 이야기, 진짜 로컬 톤 | 블로그, SNS |
| 중국 유학생 | 한국 매장 소비 경험 | 중국인 고객이 "본사 직영·재고 풍부"를 어떤 표현에서 믿는지 | 전 라인 |
| 트렌드 덕후 | 쇼츠·릴스·밈 | 형식 트렌드(트렌드조사팀과 겹침 — 팀은 수집, 이 사람은 해석) | SNS, 영상 |

쓰는 방식 두 가지:
- **기획 회의**: 편집장이 "이번 주 부천 상동점 어떻게 갈까"를 던지면 패널 5~6명이 각자 1안씩 낸다. 편집장이 취합해 기획안 카드로 만든다. (다양성은 여기서 나온다)
- **작성 렌즈**: 작성팀 작가가 글을 쓴 뒤 "시인의 눈으로 마지막 문장 다시 써봐", "영화인의 눈으로 사진 지시 다시 짜봐"처럼 특정 인물을 렌즈로 한 번 더 통과시킨다.

원칙: 패널은 의견을 내고, 결정은 편집장이, 승인은 관리자가. 패널이 많아질수록 편집장의 취합 규칙(누구 의견을 어떤 순서로, 충돌 시 무엇을 우선)이 중요해진다. 처음엔 3~4명으로 시작해 회의가 실제로 기획안 품질을 올리는지 확인하고 늘린다.

## 3. 팀 위에 있는 한 사람 — 편집장

기능팀 5개를 가로지르는 조율자가 **주간 마케팅 편집장(AI)**이다. 이미 정의서 v0.2가 있다. 역할을 블로그 한정에서 **전 라인 기획**으로 넓힌다.

- 월요일: 트렌드 보고 + 이슈 브리핑을 읽고 「주간 기획안」을 낸다. 이제 기획안에는 라인별 카드가 붙는다(블로그 9장, SNS 채널별, 이번 주 촬영·영상·POP 여부).
- 주중: 검수팀 결과를 모아 관리자에게 승인 요청.
- 금요일: 업로드팀 결과를 받아 「주간 결과 메모」.

관리자(장현진)는 편집장 하나만 상대한다. 팀 5개, 직원 15~20명을 직접 보지 않는다. → **이게 "한 화면 종합 보고"의 실체다.** 허브에 뜨는 것은 편집장의 월요일 기획안과 금요일 결과 메모, 그리고 검수 대기 목록 세 가지면 된다.

## 4. 공통 규격 (이게 없으면 합쳐지지 않는다)

모든 AI 직원과 기존 자동화 도구가 지키는 약속 4가지. 이것만 지키면 누가 무엇으로 만들었든 한 화면에 모인다.

1. **역할 정의서 양식** — 직원명 / 팀 / 관리자 / 읽는 것 / 내놓는 것 / 저장 위치 / 하지 않는 것 / 성과 지표. (01 정의서가 표준 양식)
2. **결과물 저장 위치** — 노션 「마케팅 AI 조직」 데이터베이스 하나. 페이지마다 라인 / 팀 / 지점 / 상태(초안·검수중·승인·발행·반려) / 작성자(AI 직원명 또는 도구명) / 근거(기획안·트렌드 소재 링크) 필드.
3. **상태 흐름** — 초안 → 검수중 → 승인 → 발행 (반려는 어느 단계에서든 초안으로 되돌림). 허브 칸반과 같은 흐름.
4. **금지·주의 표현 기준서** — 채널 무관 단일 문서(03 기준서). 이슈조사팀이 갱신, 검수팀이 적용, 작성팀이 프롬프트에 내장. 장대운 SNS 금지어 39개는 시범 후 이 문서로 흡수.

기존 도구(김형진 블로그 자동화, 장대운 SNS)는 코드를 안 바꾸고 **출력을 위 노션 DB 형식으로 한 번 더 저장**하는 것만 추가하면 편입 완료다.

## 5. 구축 순서 (라인을 하나씩 켠다)

원칙(v0.2, 뼈대 우선): **팀 5개·편집장·노션 DB·관점 패널을 1단계에서 한 번에 세운다.** 단, 실제로 결과물을 끝까지 흘려보는 건 블로그 라인부터. 뼈대는 한 번에, 물은 라인 하나씩. 기존 도구는 건드리지 않고 독립 운영.

| 단계 | 기간 | 켜는 것 | 완료 기준 |
|---|---|---|---|
| 0 | 완료 | 편집장 정의서 v0.2, 기준서 v0.2, 기획안 템플릿, 조직 설계서 | ✔ |
| 1 | 이번 주 | **뼈대 전부**: 노션 DB 생성 / 팀 5개 각 1명씩 정의서(쇼츠 리서처·규제 감시자·블로그 작가·규제 검수관·업로드 기록원) / 편집장 전 라인 정의서 v0.3 / 관점 패널 3명(소설·영화·시) / 블로그 라인 첫 관통 | 노션 DB에 기획안 1건 + 승인된 글 3편 이상이 정식 형식으로 존재 |
| 2 | 2~3주차 | **블로그 9지점 풀가동 + SNS 라인 켜기**: SNS 작가 추가, 검수관이 SNS도 검수. 관점 패널이 기획 회의에 실제 참여 | 블로그·SNS가 같은 DB·같은 상태 흐름. 편집장 기획안에 패널 의견·트렌드 보고가 인용됨 |
| 3 | 4~5주차 | **사진 라인**(사진 디렉터: 촬영 지시서) + 관점 패널 확장(서브컬처·카피·토박이) + 품질 검수관 | 촬영 지시서가 기획안에서 나와 승인까지 감 |
| 4 | 6~7주차 | **허브 「AI 직원」 카테고리 개설**, 승인 흐름을 노션 → 허브로 이관 | 관리자가 허브 한 화면에서 주간 상황을 봄 |
| 5 | 8~10주차 | **영상 라인**(숏폼 대본·컷 리스트) + 중국 유학생·소비심리 패널 | 숏폼 대본이 승인까지 감 |
| 6 | 11주차~ | **POP 라인**, 이미지 생성 연결, 발행 반응 → 트렌드팀 피드백 루프, 기존 도구 통합 안건 재상정 | 발행 결과가 다음 주 기획에 자동 반영 |

## 6. 관리자 결정 (2026-08-17 장현진 팀장 확정 → v0.2)

| 항목 | 결정 | 반영 |
