# 위베이프 블로그 톤 가이드 v0.1 — "안내문이 아니라 사람 말"

관리자 피드백(2026-08-17): "글이 너무 딱딱하다." 원인은 규제를 지키느라 안내문처럼 쓰는 것. 규제는 그대로 지키되, 문장은 매장에서 손님과 얘기하듯.

## 1. 우리 목소리 (표본이 오면 이 자리에 붙는다)
- 관리자가 직접 쓴 글(릴렉스 더블 / 부천 신중동 릴렉스 프로2)이 기준. 표본 파일 `tone_samples.md`가 있으면 그 문장 호흡을 최우선으로 따른다.
- 표본이 없을 때의 기준: **직영 매장 직원이 단골에게 얘기하듯.** 설명보다 장면, 정보보다 사람, 목록보다 흐름.

## 2. 반드시 지키는 문장 습관
- 첫 문장은 위치·상호가 아니라 **상황**으로 연다. (예: 퇴근길, 비 오는 날 문 앞, 자주 오시는 분이 한 말)
- 문단마다 길이가 다르게. 한 줄짜리 문단을 섞는다.
- 한 편에 **사람이 나오는 장면 2개 이상** (얼굴·이름 없이 — "저녁마다 들르시는 분", "처음 오셔서 한참 둘러보시던 분").
- 구어체 허용: "~거든요", "~더라고요", "~인데요". 단, 문단당 1회.
- 숫자·주소·전화는 본문에서 자연스럽게 한 번, 하단 정보란에 한 번.
- 마무리는 권유("~해보세요")가 아니라 **문 여는 말** ("문은 늘 열려 있어요", "지나가다 들르셔도 됩니다").

## 3. 하지 않는 것 (딱딱해지는 원인)
- 소제목을 보고서처럼 나열 ("매장 소개 / 위치 안내 / 운영 시간") — 소제목은 문장형으로, 3개 이하.
- "안내드립니다 / 제공합니다 / 확인하실 수 있습니다" 류 안내문 어미 연속.
- 필수 메시지 3종(직영·재고 안정·외국인)을 문장 그대로 붙여넣기 — 매번 장면 속에 녹여 다르게.
- 규제 준수 문장을 본문 중간에 반복 — 하단 고정 멘트 한 번이면 충분.
- 감탄사·이모지·느낌표 남발, 같은 접속사 반복("그리고", "또한").

## 4. 제목 규격
- `[지점명] 제목` 고정. 제목은 상황·사람·시간이 들어간 한 문장 (예: `[연수점] 저녁 여덟 시, 문 닫기 전에 오시는 분들`). 위치명·상호만 있는 제목 금지.

## 5. 대화 단계 (초안 → 독서가 → 수정)
- 작가 초안 → 업계 독서가가 "안내문처럼 읽히는 문장 3개 + 고칠 방향 + 지식 카드 근거"를 돌려줌 → 작가가 고쳐 쓴 뒤 검수로 넘긴다. 독서가 피드백은 노션 글 하단에 남긴다.
